# Course media provenance

The bundled course visuals were extracted from Moodle course backup media supplied by the project owner. They are used for headers and lesson context in this demonstration.

Only course overview, section, label, or resource media was considered. Student submissions, user profile images, feedback, grading annotations, and other learner records were explicitly excluded.
